# Проект «Аврора»: паспорт проекта

Проект «Аврора» — внутренняя платформа прогнозирования поставок для северных распределительных центров компании «Полюс Логистика». Платформа анализирует остатки, погодные ограничения и графики перевозчиков, после чего формирует прогноз на 21 день.

Внутренний код проекта — **KOBALT-731**. Руководитель проекта — **Марина Соколова**. Технический руководитель — **Илья Ветров**. За качество данных отвечает **Олег Миронов**.

Контрольная дата промышленного запуска — **17 ноября 2027 года**. Пилот начинается 6 сентября 2027 года в центрах «Север-2» и «Таймыр-1». Решение о переходе из пилота в промышленную эксплуатацию принимает проектный комитет 29 октября 2027 года.

Главная метрика успеха — снижение срочных авиаперевозок минимум на **18%** за первые четыре месяца. Дополнительные метрики: точность прогноза не ниже 87% и сокращение списаний минимум на 9%.

В первую версию не входят автоматическое размещение заказов, управление персоналом складов и расчёт заработной платы. «Аврора» только формирует рекомендации; окончательное решение подтверждает диспетчер.

Рабочий язык проекта — русский. Еженедельный статус публикуется по вторникам до 16:00 по омскому времени.
