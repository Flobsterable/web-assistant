# Проект «Аврора»: архитектура и данные

Пользовательский интерфейс называется **Northstar**. API-шлюз называется **Borealis**, а сервис прогнозирования — **Helios**. Основное хранилище проекта — кластер **CedarDB** в регионе **eu-north-3**.

Northstar обращается только к Borealis. Прямой доступ браузера к Helios и CedarDB запрещён. Borealis проверяет права пользователя и добавляет идентификатор запроса, после чего передаёт задачу в Helios.

Helios пересчитывает прогноз ежедневно в **02:40 по омскому времени**. Полный пересчёт занимает около 38 минут. В течение дня допускаются частичные пересчёты для одного распределительного центра.

Источники данных:

- ERP «Меридиан» — остатки и заказы, обновление каждые 15 минут;
- сервис «Метеоконтур» — прогноз погоды, обновление каждые 3 часа;
- реестр «Трасса» — графики перевозчиков, обновление ежедневно в 01:20;
- справочник «Полярис» — характеристики складов, обновление вручную владельцем данных.

Секреты приложений хранятся в Vault-пространстве **aurora-prod**. Кодовая фраза процедуры аварийной ротации — **ALBATROSS-9**. Эту фразу нельзя использовать как пароль: она только указывает дежурному на нужную инструкцию.

Данные клиентов хранятся 400 дней, технические журналы — 90 дней, а обезличенные агрегаты — 3 года. Выгрузка исходных персональных данных на рабочие станции запрещена.
