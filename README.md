# Quanta — локальная индексация документов

Fullstack-приложение на React, TypeScript и Express. Проект реализует полный ingestion-пайплайн для локальной базы знаний: извлечение текста, две стратегии chunking, генерацию эмбеддингов, сохранение индекса и визуальное сравнение результата.

Day 21 встроен поверх функциональности предыдущих этапов. В приложении сохранены полноценный агент, история чатов, управление контекстом и токенами, рабочая и долгосрочная память, профили, инварианты, состояния задач, Planner, MCP connections и Google Calendar MCP.

## Что реализовано

- Поддержка `.md`, `.mdx`, `.txt`, `.html`, `.json`, `.js`, `.jsx`, `.ts`, `.tsx`, `.css`, `.py` и `.pdf`.
- PDF преобразуется в текст локальной утилитой `pdftotext` (Poppler).
- Фиксированный chunking: окно 1 200 символов, overlap 180 символов.
- Структурный chunking: границы Markdown-заголовков/разделов, максимум 1 800 символов.
- Для каждого чанка сохраняются `source`, `title`, `section`, `chunk_id`, стратегия, текст, число токенов и embedding.
- Автономные 128-мерные эмбеддинги на основе signed feature hashing; внешний API не требуется.
- Индекс атомарно сохраняется в `server/data/index.json`.
- Векторный поиск использует косинусную близость.
- Отдельный экран `#index`: схема процесса, реальные метрики, сравнение стратегий, просмотр чанков и поиск по активной стратегии.
- Параметры chunking, загрузка документов, выбор стратегии и схема процесса спрятаны в компактные раскрывающиеся панели.
- Активная стратегия — рабочая настройка агента: она применяется к обычным сообщениям, прикреплённым документам и поиску по локальному индексу.
- Настройки chunking: фиксированный размер, overlap и максимальный размер структурного раздела.

Синтетический корпус не создаётся. Пока пользователь не загрузил реальные документы, индекс остаётся пустым. Файлы можно добавить на экране «Индексация» или прикрепить непосредственно к сообщению агенту; после загрузки они сохраняются в `server/data/documents` и автоматически индексируются.

При каждом запросе агент самостоятельно ищет релевантные фрагменты в локальном индексе и получает их как защищённый справочный контекст. Если документ прикреплён к сообщению, его фрагменты приоритетно передаются агенту в текущем запросе. Стратегию можно переключить на экране индексации или в отдельном окне настроек агента; выбор сохраняется в браузере и передаётся серверу с каждым запросом.

В окне настроек также можно очистить историю текущего чата или удалить все сохранённые диалоги.

## Структура индекса

```json
{
  "embedding_model": "local-hashing-embedding-v1",
  "embedding_dimensions": 128,
  "document_count": 25,
  "strategies": {
    "fixed": { "chunks": 75, "average_chars": 956 },
    "structural": { "chunks": 100, "average_chars": 602 }
  },
  "chunks": [
    {
      "content": "...",
      "metadata": {
        "source": "chapter-1-01.md",
        "title": "Архитектура RAG",
        "section": "Задача",
        "chunk_id": "str-...",
        "strategy": "structural"
      },
      "embedding": [0.04, -0.08, 0.0],
      "token_count": 142
    }
  ]
}
```

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Frontend: `http://localhost:5173`. Экран индексации: `http://localhost:5173/#index`.

Ключ DeepSeek нужен только для чата. Индексация и поиск полностью локальны.

Основные разделы доступны через новую навигацию: «Ассистент», «Планировщик», «MCP» и «Индексация». Для Google Calendar и дополнительных моделей используйте переменные из `.env.example`.

## Команды

```bash
npm run index   # собрать локальный индекс без запуска web-сервера
npm run build   # проверить TypeScript и production-сборку
npm start       # запустить собранный Express-сервер
```

## API

- `GET /api/index` — получить индекс; при отсутствии он будет создан.
- `POST /api/index/rebuild` — перечитать документы и перестроить индекс.
- `POST /api/index/search` — поиск, тело: `{ "query": "...", "strategy": "structural" }`.
- `GET /api/documents` — список реальных документов в локальном хранилище.
- `POST /api/documents/upload` — загрузить документ и автоматически обновить индекс.
- `DELETE /api/documents` — удалить все загруженные документы и пересобрать пустой индекс.
- `DELETE /api/documents/:name` — удалить документ и его чанки из индекса.
- `POST /api/agent` — запрос агенту; поле `retrievalStrategy` принимает `fixed` или `structural`.
- `DELETE /api/agent/history?sessionId=...` — очистить текущий диалог и его рабочие данные.
- `DELETE /api/agent/chats` — удалить всю историю диалогов.
- `POST /api/chat` — существующий чат через DeepSeek.

Для больших коллекций JSON-хранилище можно заменить на SQLite или FAISS: контракт чанка и UI останутся прежними.
